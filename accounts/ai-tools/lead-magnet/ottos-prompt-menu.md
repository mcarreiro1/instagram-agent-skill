## BREAKFAST · set it up once

**1. The Settings Stack**
*Paste into your custom instructions (or the "about me" / personalisation
settings in whatever tool you use). It reads this before every new chat.*

```
About me: I'm a [job] at/for [type of business]. My customers/audience are
[who]. I mostly use you for [3 tasks].
How to answer: plain English, no jargon. Under [150] words unless I ask for
more. Use bullet points for steps. If my request is vague, ask me one
question before answering. Never make up facts, numbers or sources. Say
"I don't know" instead.
```

> **OTTO:** Tell it once. Not 40 times, Dad.

**2. The Interview Omelette**
*Add to the end of any big request.*

```
Before you answer, ask me 3 questions that would most change your answer.
Wait for my replies.
```

**3. The Short Stack**

```
Answer in under 100 words. If it really needs more, tell me what you left
out and ask if I want it.
```

**4. The Clean Slate**
*Long chat getting dumb? Run this, then paste the result into a new chat.*

```
Summarise this conversation so I can continue in a new chat: my goal, the
decisions we made, the facts about me and my situation, and the open
questions. Bullet points, under 200 words.
```

## MAINS · get the work done

**5. The Match-This Melt**

```
Here's an example of a [email / menu / post] I wrote that sounds like me:
[paste example]
Write a [new thing] about [topic] in the same tone, length and structure.
Don't add anything the example doesn't have, like emojis or exclamation marks.
```

> **OTTO:** One example beats ten adjectives.

**6. The Three-Way Platter**

```
Give me 3 genuinely different versions: one short, one warm, one formal.
Label each one.
```

**7. The Merge**

```
I like the opening of version [2] and the ending of version [3]. Combine
them into one, keep it under [100] words, and change nothing else.
```

**8. The Email I've Been Avoiding**

```
Here's the email I need to reply to:
[paste]
What I actually want to say: [one sentence, as blunt as you like].
Write a reply under 120 words. Polite, clear, apologise at most once, and
end with one specific next step.
```

**9. The Meeting Notes Hash**

```
Here are my rough notes:
[paste]
Turn them into three lists: decisions made, action items (who + by when),
and open questions. Don't add anything that isn't in my notes. If an owner
or date is missing, write [missing].
```

**10. The Spreadsheet Scramble**

```
I'm using [Excel / Google Sheets]. Column [A] has [what's in it], column [B]
has [what's in it]. In column [C] I want [result]. Give me the formula, then
explain each part in one line. Tell me what will break it.
```

**11. The Week Planner**

```
Here's my to-do list:
[paste]
I have about [hours] free this week, mostly on [days]. Sort it into must /
should / could, estimate how long each takes, and put the musts on specific
days. Be realistic: leave 20% of the time empty.
```

**12. The Plain-English Plate**

```
Explain this [contract / letter / policy] in plain English for someone with
no background in it:
[paste, with names and account numbers removed. See #15]
Then list the 3 things I should ask a professional about before I act on it.
```

> **MARTY:** It's not a lawyer.
> **OTTO:** That's why it tells you what to ask the lawyer!

## SIDES · trust, but check

**13. The Fact-Check Flapjack**
*Run it after any answer with facts in it.*

```
For every factual claim in your last answer, rate your confidence (high /
medium / low) and tell me exactly what I'd search to check it. Flag anything
you can't back with a source I can open.
```

**14. The Source Sizzler**
*Use with web search turned on.*

```
Only use sources you can link to, and give me the link next to each claim.
If you can't find a source, write "no source" instead of guessing.
```

> **OTTO:** Then CLICK the links. Every one.

**15. The Redacted Reuben**
*Do this before you paste anything private. It's a checklist, not a prompt.*

- Swap names for `[CLIENT]`, `[LANDLORD]`, `[ME]`
- Swap amounts, account numbers and addresses for `[AMOUNT]`, `[ACCOUNT]`, `[ADDRESS]`
- Check your tool's data or privacy settings, and your workplace's AI policy
- Then add this line:

```
Words in [brackets] are real details I removed on purpose. Keep them
exactly as they are in your answer.
```

**16. The Devil's Advocate Danish**

```
Here's my plan:
[paste]
Argue against it. Give me the 3 strongest reasons it could fail, how likely
each one is, and the cheapest way to test each one this week.
```

## TODAY'S SPECIALS

**17. The Interview Pancake**

```
Act as the hiring manager for a [role] at a [type of company]. Ask me one
interview question at a time and wait for my answer. After each answer,
give me 2 lines of feedback: what worked, what to fix. Stop after 5
questions and tell me my weakest area.
```

**18. The Recruiter Read**

```
Read my CV as a recruiter hiring for [role]:
[paste, with your address and phone number removed]
What do you notice in the first 10 seconds? What's missing for this role?
Give me the 3 changes that matter most, in order.
```

**19. The Teach-Me Toast**

```
Explain [topic] like I'm smart but completely new to it. Use one everyday
analogy. Then ask me 3 short questions to check I understood, one at a time.
```

**20. The Prompt Fixer**

```
Here's a prompt I wrote: [paste your prompt]
Before rewriting it, ask me what's missing. Then rewrite it so I get a
better answer, and tell me what you changed and why.
```
